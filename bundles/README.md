# bundles/

English · [简体中文](#简体中文)

This directory holds the Blue Archive resource bundle that the retired daily publishing attached to its `build-r*-u*` pre-releases: `<game>-bundle-<sha7>.zip` and its `.sha256` sidecar (check it with `sha256sum -c`). It is kept for reference and is no longer updated. Versioned releases `vX.Y.Z` take each game's standard resource package from that resource repository's own release instead.

## 简体中文

本目录存放以前每日发布附进 `build-r*-u*` 预发布的蔚蓝档案资源包：`<game>-bundle-<sha7>.zip` 及其 `.sha256` 校验文件（可用 `sha256sum -c` 校验）。仅作参考保留，不再更新。按版本号发布的 `vX.Y.Z` 改为直接取各游戏资源仓自己发布的标准资源包。
